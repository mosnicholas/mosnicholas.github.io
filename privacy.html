Privacy policy

Last updated: October 9, 2026

Hermes (home) is a private assistant used only by its owner. This page explains how it handles the Google data its owner authorizes it to use.

What it accesses

With the owner's permission, it reads the owner's Gmail messages and Google Calendar, creates email drafts, sends a draft only after the owner approves that specific message, and changes calendar events only after the owner approves that specific change.

How the data is used

The data is used only to provide the assistant to its owner. It is processed on the owner's own server. To answer the owner's requests, message content may be sent to AI model providers that process it on the owner's behalf. It is not sold, not used for advertising, and not shared with anyone else.

Storage and deletion

The Google sign-in credential is stored only on the owner's server. The owner can revoke access at any time at myaccount.google.com/permissions, after which the assistant can no longer read or change anything.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
